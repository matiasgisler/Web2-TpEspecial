Para poder ejecutar este proyecto deben estar administrados los archivos de la siguiente manera(no saltearse ninguna mayusculas pls!)
Pagina (la carpeta principal del proyecto)
dentro de esta carpeta crear las siguientes carpetas
-controladores
-middlewares
-modelos
-vistas
Ademas de las carpetas poner los archivos
-.htaccess
-router.php
y por ultimo agregar a cada carpeta sus respectivos archivos
Por cierto modifique la BD, asique la mando tambien
//Se debe agregar al README.md una breve explicación de cómo desplegar el sitio en un servidor con Apache y MySQL, como también cualquier información necesaria para su uso, como pueden ser usuarios y contraseñas de administrador.//
Para poder ejecutar este proyecto lo que deben hacer una vez descargado el xampp
1.iniciar los servicios de Apache y MySQL
2.tocar Admin en MySQL y importar la BD
3.ir a tu htdocs y agregar la carpeta de pagina
4. en tu navegador poner http://localhost/TPESPECIALWEB2(o el nombre de la carpeta donde guardes el proyecto)/Pagina/inicio
5. disfrutar la pagina, el usuario creado es nombre=webadmin contrasenia=admin
